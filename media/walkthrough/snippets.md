# Type a prefix, press Tab

Open any `.tsx`, `.ts`, `.jsx` or `.js` file and type one of these, then press **Tab**:

| Prefix | You get |
| --- | --- |
| `rn` | Component named after its folder |
| `rn-props` | Component with typed `Props` |
| `rn-fl` | `FlatList` with `keyExtractor` and `renderItem` |
| `rn-ctx` | Context + Provider + `useXxx()` hook |
| `ust` / `uef` | `useState` / `useEffect` |

Press **Tab** again to jump to the next field. In `rn-ctx`, type the name once and it fills in everywhere.
