# Copilot can fetch the templates itself

This extension adds a **React Native Snippets** MCP server to Copilot. Nothing to set up.

1. Open the Chat view and switch to **Agent** mode.
2. Ask for React Native code, for example: *"Create an auth context"*.
3. Copilot calls `list_snippets` / `get_snippet` and builds on the template. Click **Allow** the first time.

To check it's there, click the **Configure Tools** icon in the chat box and look for **React Native Snippets**.

Using Cursor or Claude Code? See *Use with AI* in the extension's README for the one-line MCP setup.
